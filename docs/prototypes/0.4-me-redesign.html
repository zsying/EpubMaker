「我的」页重构 · 设计稿

0.4 · 已定稿并实现 · 词库停在浮层 · 无统计条 · 补字号 · 分区名用「笔记」

现在的「我的」是 7 条同级条目 + 一个游离在列表外的「查词词库」按钮，没有分组、没有状态、没有主次； 「设置」里字体摊开 8 个 chip、AI 却是单独一行入口 —— 同一件事两种层级。 这一稿把「我的」重排成 4 个意图片区 / 两种行规格 / 每行带当前值，并把「设置」内部拉平成同一种结构。

一 · 三条规则

决定后面每一行的位置
1

按「意图」分区，不按「页面」罗列

用户来这里只有四件事：调阅读、看笔记、搬书、配 AI / 排障。 分区名就是这四件事，页面（WebDAV、回收站、日志）只是各自的下属。

2

主次靠规格，不靠排序

高频的两行用大行 + 彩色图标块（36px 图标、双行摘要），其余用标准行 + 灰图标（32px 单行）。 一眼就能分出「常用」和「偶尔」。

3

要预览的留在原地，要浏览的下沉一层

主题色块、翻页分段、开关 —— 改完立刻能看见，留在行内。字体是一长串列表、AI 是一整套表单， 两者都收成「一行摘要 → 进下一层」，层级因此一致。

五 · 已定的四项

按此实现
1
「查词词库」停在浮层

不新建独立页。它有四个动作、没有自己的内容，浮层里给状态卡 + 来源列表就够了； 「查词历史」「生词复习」仍留在生词本，不搬。

2
不放顶部统计条

首屏留给四个分区，不争抢注意力。数量改成每行自己的当前值（书签 12 / 划线 38 / 回收站 3）， 信息没有丢，只是分散到该在的位置。

3
设置补「字号」

一行 A− / 17 / A+，范围 13–26（与阅读器 Aa 面板同一套钳制），写同一个 epubmaker.fontSize，不必先打开一本书。

4
分区用短名，第二组叫「笔记」

阅读 / 笔记 / 书库 / AI 与系统。用户口语里划线+批注就是「笔记」（术语仍是「批注」）。

实现备注：统计值不新增后端方法 —— 书签/划线复用 ListAllBookmarks / ListAllAnnotations 取长度，回收站用 ListTrash，AI 用 GetAIConfig；任何一条失败只让那一行少一个数字，页面照常。 两页都收在 640px 列内（桌面上 /me 只靠 URL 到达）。 新增 --warn / --warn-soft 两个主题变量（未安装 / 未配置要读作"待处理"而非"出错"）， 深色与墨蓝另外提亮了 --ok / --danger。
